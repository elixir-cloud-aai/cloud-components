## Overview

A form for submitting a task to a GA4GH Task Execution Service (TES). It supports executors (image, command, environment, std streams), inputs, outputs, resources, tags and volumes.

## Usage

<Tabs items={['React', 'HTML']}>
  <Tabs.Tab>
    ```tsx showLineNumbers copy filename="run-create.tsx"
    import { ECCClientGa4ghTesRunCreate } from '@elixir-cloud/tes/react';

    export default function RunCreate() {
      return (
        <ECCClientGa4ghTesRunCreate
          baseUrl="https://protes.rahtiapp.fi/ga4gh/tes/v1"
          onEccRunSubmitted={(e) => console.log(e.detail.runId)}
          onEccRunCreateFailed={(e) => console.error(e.detail.error)}
        />
      );
    }
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```html showLineNumbers copy filename="run-create.html"
    <script type="module" src="https://esm.sh/@elixir-cloud/tes"></script>

    <ecc-client-ga4gh-tes-run-create
      baseUrl="https://protes.rahtiapp.fi/ga4gh/tes/v1"
    ></ecc-client-ga4gh-tes-run-create>
    ```
  </Tabs.Tab>
</Tabs>

## Properties

| Property   | Type          | Default | Description |
|------------|---------------|---------|-------------|
| `baseUrl`  | `string`      | `""`    | Base URL of the TES API. |
| `provider` | `TesProvider` | `undefined` | Custom provider; overrides `baseUrl`. |

## Events

| Event                   | Detail                                  | Description |
|-------------------------|-----------------------------------------|-------------|
| `ecc-run-submitted`     | `{ runId: string, request: TaskRequest }` | A task was created. |
| `ecc-run-create-failed` | `{ error: string }`                     | Creating the task failed. |
| `ecc-run-create-reset`  | none                                    | The form was reset. |
