## Overview

The `ecc-client-ga4gh-service-registry-service-info` component shows the service info of a GA4GH Service Registry itself (`GET /service-info`): its name, ID, version, type and organization, and the optional fields that the registry sets.

Optional fields that are missing or invalid are left out. Links are shown only for `http:` and `https:` URLs (and `mailto:` for the contact).

## Properties

| Property   | Attribute | Type                      | Default     | Description                                                                                |
|------------|-----------|---------------------------|-------------|--------------------------------------------------------------------------------------------|
| `baseUrl`  | `baseurl` | `string`                  | `""`        | Base URL of the Service Registry API, used if no `provider` is set                         |
| `provider` | -         | `ServiceRegistryProvider` | `undefined` | Data provider for fetching the service info (see [Providers](/docs/service-registry/providers)) |

Set one of them; without either, the component shows an error. Changing either loads the service info again.

### `provider`
The data provider whose `getServiceInfo()` returns the service info. See the [Providers documentation](/docs/service-registry/providers) for the available providers and how to create custom ones.

<Tabs items={['React', 'HTML']}>
  <Tabs.Tab>

    ```tsx copy
    const provider = new RestServiceRegistryProvider('https://registry.example.com/ga4gh/registry/v1');

    ```

## Events

| Event Name                 | React Event Name          | Detail Type                       | Description                                |
|----------------------------|---------------------------|-----------------------------------|--------------------------------------------|
| `ecc-service-info-changed` | `onEccServiceInfoChanged` | `{ serviceInfo: Service \| null }` | Fired when the service info data changes   |

### `ecc-service-info-changed`
Emitted when the service info is loaded. If loading fails, or the provider is removed, `serviceInfo` is `null`.

<Tabs items={['React', 'JavaScript']}>
  <Tabs.Tab>
    ```tsx copy
    <ECCClientGa4ghServiceRegistryServiceInfo
      onEccServiceInfoChanged={(event) => {
        document.title = event.detail.serviceInfo?.name ?? 'Service Registry';
    ```
