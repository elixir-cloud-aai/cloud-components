## Overview

The `ecc-client-ga4gh-service-registry-service-info` component displays the service info of a GA4GH Service Registry itself (`GET /service-info`): its name, ID, version, type, organization and description, and the optional environment, contact, documentation and timestamps.

Optional fields are shown only if they are set, so that a registry that sets few of them shows no placeholders, invalid values or dead links. Fields that are blank or not strings (from a registry that does not follow the specification) are left out too:

- `environment` (as a badge next to the type and in the details), `description`: shown if not empty.
- `contactUrl`: shown as a link if it is an `http:` or `https:` URL, or a `mailto:` URL whose recipients are all email addresses without control or format characters (such as zero-width spaces or bidi overrides). The recipients must be in the URL's path (`mailto:help@example.org`), not only in `?to=`. A `mailto:` link shows only these recipients, without the scheme or options such as `?subject=`, `?cc=` or `?bcc=`; the reader's mail client shows all recipients before sending.
- `documentationUrl`, `organization.url`: shown as links if they are `http:` or `https:` URLs; without a valid URL, the organization shows its name only.
- `createdAt`, `updatedAt`: shown in the reader's locale if they are RFC 3339 timestamps of a real calendar date, such as `2026-01-02T03:04:05Z`. A space or a lowercase `t` between date and time and a missing offset (read as the reader's local time) are tolerated; leap seconds aren't, as browsers can't parse them. Other values are left out. Since cloud-registry 0.4.0, a fresh deployment sets neither.

The heading shows the `name`, or else the `id`, or else "Service Registry". The type badge (`artifact@version`) needs a `type.artifact`; the Type row shows the parts of the type that are set.

While the service info loads, the component shows placeholders; a failed request, or a response that is not an object, shows its error.

## Properties

| Property   | Attribute | Type                      | Default     | Description                                                                                |
|------------|-----------|---------------------------|-------------|--------------------------------------------------------------------------------------------|
| `baseUrl`  | `baseurl` | `string`                  | `""`        | Base URL of the Service Registry API, used if no `provider` is set                         |
| `provider` | -         | `ServiceRegistryProvider` | `undefined` | Data provider for fetching the service info (see [Providers](/docs/service-registry/providers)) |

Without either, the component shows an error that asks for one. A `provider` (or `baseUrl`) that is set or replaced after the first update loads the service info again, and only the latest load applies (see [Providers](/docs/providers)); removing the `provider` falls back to the `baseUrl` if one is set, and removing both clears the service info and shows the error.

### `provider`
The data provider whose `getServiceInfo()` returns the service info. See the [Providers documentation](/docs/service-registry/providers) for the available providers and how to create custom ones.

<Tabs items={['React', 'HTML']}>
  <Tabs.Tab>
    ```tsx copy
    import { RestServiceRegistryProvider } from '@elixir-cloud/service-registry/providers';

    const provider = new RestServiceRegistryProvider('https://registry.example.com/ga4gh/registry/v1');

    <ECCClientGa4ghServiceRegistryServiceInfo provider={provider} />
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```html copy
    <script type="module">
      import { RestServiceRegistryProvider } from '@elixir-cloud/service-registry/providers';

      const provider = new RestServiceRegistryProvider('https://registry.example.com/ga4gh/registry/v1');

    </script>
    <ecc-client-ga4gh-service-registry-service-info></ecc-client-ga4gh-service-registry-service-info>
    ```

## Events

| Event Name                 | React Event Name          | Detail Type                       | Description                                |
|----------------------------|---------------------------|-----------------------------------|--------------------------------------------|
| `ecc-service-info-changed` | `onEccServiceInfoChanged` | `{ serviceInfo: Service \| null }` | Fired when the service info data changes   |

### `ecc-service-info-changed`
Emitted whenever the service info is loaded. When a load fails or the provider is removed, it is emitted with `serviceInfo: null`, so that an app drops the service info of the previous registry too.

<Tabs items={['React', 'JavaScript']}>
  <Tabs.Tab>
    ```tsx copy
    <ECCClientGa4ghServiceRegistryServiceInfo
      onEccServiceInfoChanged={(event) => {
        document.title = event.detail.serviceInfo?.name ?? 'Service Registry';
      }}
    />
    ```
  </Tabs.Tab>

  <Tabs.Tab>
    ```javascript copy
    element.addEventListener('ecc-service-info-changed', (event) => {
      document.title = event.detail.serviceInfo?.name ?? 'Service Registry';
    });
    ```
  </Tabs.Tab>
</Tabs>
